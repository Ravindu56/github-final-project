# Simple Interest Calculator

A simple Bash script that calculates **Simple Interest** based on user-provided inputs. This project is part of an open source initiative to empower micro-finance institutions with accessible, transparent financial tools.

## Description

Simple Interest is calculated using the formula:

**Simple Interest (SI) = (Principal × Rate × Time) / 100**

This script prompts the user to enter:
- **Principal** – The initial amount of money
- **Rate of Interest** – Annual interest rate (in %)
- **Time Period** – Duration (in years)

It then outputs the calculated Simple Interest.

## Getting Started

### Prerequisites

- A Unix/Linux/macOS terminal **or** Git Bash on Windows
- `bash` shell (version 3.x or later)
- `bc` utility (basic calculator — usually pre-installed on Linux/macOS)

### Installation

Clone this repository to your local machine:

```bash
git clone https://github.com/<your-username>/github-final-project.git
cd github-final-project
```

### Usage

Make the script executable and run it:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

**Example Interaction:**

```
Enter Principal:
1000
Enter Rate of Interest (in %):
5
Enter Time Period (in years):
3
Simple Interest = 150.00
```
